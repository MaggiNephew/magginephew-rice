THE LOOK

Everything is black, white and gray: the bar, the lock screen, the file manager, the terminal, even the stream overlays. One font family, one frame shape, one line that moves with the music.

WHAT'S INSIDE

Hyprland

Lua config, monochrome borders and gaps, scroll-to-switch workspaces, scratchpad, and games that keep running at full speed on other workspaces.

Quickshell bar

Hand-written in QML. Workspaces, a clock with a music-reactive line on both sides, CPU / RAM / network, Wi-Fi, VPN, update badge and a mic/camera privacy light.

Media player

Click the music pill: cover, controls, seek, volume, pick the output device with scroll / arrows / Enter, plus a pull-out library and downloader.

Local music

An mpv-based player with its own library, a downloader that tags songs (MusicBrainz + cover art), and a Brave extension that adds the YouTube song you're on to the library.

Soundboard + Rice Mic

A virtual mic = your mic + clips + any app you choose to share. Works in Discord, games and calls. Super+Alt+1–9 plays clips.

Start menu, calendar, clipboard

Windows-style menu on the Arch logo with pins and recent files, a month calendar on the clock, and clipboard history with image previews on Super+C.

Orbital lock + login

One animated lock screen for both boot and Super+L — Quickshell for the session, SDDM for login — so they look identical.

MonoBW theme

A KDE / Qt colour scheme and light-gray folder icons so Dolphin and every Qt app match, with readable white text and dark-gray selection.

cyber

A terminal browser for the BlackArch tool collection with mouse support, and a one-key firejail sandbox (with or without network) for running tools safely.

safe-update

Updates that can't leave you in emergency mode: snapshot first, run where a desktop crash can't interrupt it, check the kernel / initramfs / NVIDIA / boot menu, repair or roll back.

Snapshots + firewall

rice-system-setup: snapper with automatic snapshots before every update, Limine boot entries for them, and a deny-incoming firewall.

Stream kit

OBS scenes and browser overlays in the same style: starting / BRB / ending screens, camera frame, follower alerts, live counters, chat, and scene hotkeys that work in-game.

USE IT

These are my personal dotfiles, not an installer — take what you like. Back up your own configs first.

git clone https://github.com/MaggiNephew/magginephew-rice
cd magginephew-rice
cp -r config/hypr config/quickshell config/kitty config/cava ~/.config/
cp bin/* ~/.local/bin/

Main packages: hyprland quickshell kitty cava pipewire wireplumber playerctl brightnessctl cliphist wl-clipboard mpv mpv-mpris yt-dlp python-mutagen firejail snapper qt6ct dolphin fastfetch ttf-3270-nerd. The full list and folder-by-folder notes are in the README.

WALLPAPERS

All of them are in the wallpapers folder. The ones in wallpapers/daily rotate one per day (wallpaper-daily), Super+W skips to the next.

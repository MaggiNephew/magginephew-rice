# Screenshots

Drop PNGs here with these exact names (any you skip simply don't show on the site):

| file | what to capture |
|---|---|
| desktop.png | whole screen: wallpaper, bar, a couple of tidy windows |
| bar.png | just the bar, with music playing so the line moves |
| media.png | media popup open, library drawer pulled out |
| start-menu.png | start menu open |
| soundboard.png | soundboard popup open |
| calendar.png | calendar or clipboard panel open |
| lock.png | lock screen (`orbital-lock --test` shows it in a window) |
| terminal.png | kitty with fastfetch, or the `cyber` browser |
| files.png | Dolphin |
| stream.png | OBS with the Live or Just Chatting scene |

Use `Super+Shift+Print` (whole screen) or `Super+Print` (region). Close anything private first
(chat, emails, notifications, browser tabs).
